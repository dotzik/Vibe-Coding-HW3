# Stručné system prompty

System prompt agenta má mít 2 až 4 věty, žádnou omáčku.

**Proč:** Dlouhé system prompty se posílají při každém volání a zbytečně
spotřebovávají tokeny, aniž by zlepšily kvalitu rozhodnutí.

**Jak aplikovat:** Roli agenta popsat co nejstručněji. Detailní instrukce
patří do per-úkol promptu, ne do system promptu.
