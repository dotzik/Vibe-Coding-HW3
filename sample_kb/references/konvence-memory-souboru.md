# Konvence memory souborů

Každý memory soubor drží právě jeden fakt: jeden soubor = jedno téma.
Soubor má YAML frontmatter mezi `---`, pod ním H1 titulek a krátké tělo.
Odkazy mezi soubory se píší dvojitými hranatými závorkami kolem slugu a
míří na název cílového souboru bez přípony. Index všech souborů je v
souboru `MEMORY.md`.
